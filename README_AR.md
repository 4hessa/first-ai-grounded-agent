# مشروع FirstAI Grounded Agent

مشروع تطبيقي لبناء وكيل ذكاء اصطناعي عربي يركز على هندسة النظام المحيط بالنموذج، وليس على استدعاء النموذج فقط. يدمج المشروع الاتصال بخدمة نماذج إنفيديا، استخدام الأدوات، البحث في ملفات معرفة محلية، التحقق من المراجع، الملاحظات الدائمة التي يحفظها المستخدم صراحة، البحث المتفرع بين عمال مستقلين، وآليات تحقق واسترداد محدودة قبل عرض الجواب النهائي.

## الفكرة

الهدف هو تحويل نموذج لغوي إلى تطبيق وكيل أكثر انضباطًا. يضع البرنامج حدودًا واضحة لعدد الطلبات وحجم السياق، يسمح فقط بأدوات معروفة، يعامل محتوى ملفات المعرفة كبيانات غير موثوقة، ويتحقق من أن المراجع التي يذكرها الجواب جاءت فعلًا من المقاطع المسترجعة.

## النموذج الافتراضي

نموذج المحادثة:

```text
nvidia/nemotron-3-super-120b-a12b
```

نموذج التضمين الاختياري للبحث الدلالي:

```text
nvidia/llama-nemotron-embed-vl-1b-v2
```

## أهم المكونات

1. حلقة وكيل تستدعي النموذج وتنفذ الأدوات المسموحة ثم تعيد نتيجة الأداة للنموذج.
2. أداة حساب محدودة لا تنفذ شيفرة عامة.
3. بحث محلي في ملفات المعرفة مع معالجة محدودة لبعض صيغ الكلمات العربية.
4. بحث دلالي اختياري باستخدام متجهات التضمين.
5. إجابات مستندة إلى المصادر مع معرفات مقاطع قابلة للتحقق.
6. ملاحظات دائمة محلية لا تحفظ إلا بأمر صريح من المستخدم.
7. بحث متفرع يبدأ بخطة ثم عمال بسياقات مستقلة ثم مرحلة جمع نهائية.
8. حفظ مسودات البحث وإمكانية استكمال مرحلة الجمع عند تحقق شروط السلامة.
9. مراجعة لغوية محدودة تمنع خلط المصطلحات الأجنبية داخل السطر العربي وتحافظ على المراجع والأرقام والروابط وأمثلة الشيفرة.
10. معالجة آمنة نسبيًا لأخطاء الاتصال بحيث لا يعرض البرنامج مفتاح الخدمة أو نصوص الخطأ البعيدة.

## حدود مهمة

عزل سياق العمال لا يعني عزل التشغيل. المشروع لا يعزل العمليات أو الملفات أو الشبكة بنفسه. عزل التشغيل يحتاج بيئة وسياسة خارجية مضبوطة ومختبرة. كما أن التحقق من معرف المرجع يثبت أن المصدر كان ضمن الأدلة المتاحة، لكنه لا يثبت تلقائيًا صحة كل استنتاج كتبه النموذج.

## التشغيل

فحص محلي دون اتصال:

```bash
python -m first_ai doctor
```

عرض ثابت دون نموذج:

```bash
python -m first_ai demo
```

الاختبارات:

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

محادثة حية بعد ضبط مفتاح إنفيديا محليًا:

```bash
python -m first_ai chat
```

## نتيجة الاختبارات

نسخة المحفظة اجتازت 108 اختبارات محلية حتمية تغطي حلقة الوكيل، الأدوات، البحث، المراجع، أخطاء الاتصال، البحث المتفرع، الاستكمال، حدود الطلبات، ومراجعة اللغة.

## كيف يكتب في السيرة الذاتية

مشروع FirstAI Grounded Agent: تصميم وتنفيذ وكيل ذكاء اصطناعي عربي باستخدام NVIDIA NIM، مع استرجاع معرفة مستند إلى المصادر، استخدام أدوات مقيدة، ذاكرة يسيطر عليها المستخدم، بحث متفرع، تحقق من المراجع، حدود لطلبات النموذج، ومعالجة أخطاء واختبارات انحدار واسعة.

## المصدر التعليمي

تطور المشروع أثناء دراسة مفاهيم دورة NVIDIA DLI الخاصة بحلقات الوكلاء، التنسيق بين الوكلاء، الاسترجاع المستند إلى المعرفة، NemoClaw وOpenShell. المشروع مستقل وليس منتجًا أو اعتمادًا من إنفيديا. راجع ملف NOTICE للتفاصيل.
