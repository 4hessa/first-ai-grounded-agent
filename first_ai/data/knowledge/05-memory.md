# سياق المحادثة والذاكرة الدائمة
سياق المحادثة هو التاريخ المؤقت الذي يرسل إلى النموذج أثناء الجلسة الحالية ضمن حد محدد من التبادلات.
الذاكرة الدائمة تحتاج حفظًا خارجيًا مقصودًا خارج سياق المحادثة، ثم تُقرأ لاحقًا عند بدء تشغيل جديد.
مسح سياق المحادثة لا يعني حذف الملاحظات التي حفظها المستخدم صراحة في التخزين المحلي.
في هذا المشروع لا يؤدي قول كلمة احفظ داخل المحادثة إلى كتابة ملاحظة؛ الحفظ يتم عبر أمر محلي مخصص حتى يبقى القرار بيد المستخدم.
